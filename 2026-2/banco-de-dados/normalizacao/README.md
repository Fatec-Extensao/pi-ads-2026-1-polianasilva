
## Normalização

O mapeamento atual do banco de dados está normalizado, atendendo às três primeiras Formas Normais (FN).

### Justificativa

1. **Primeira Forma Normal (1FN):** Todos os atributos são monovalorados e atômicos.

2. **Segunda Forma Normal (2FN):** Todos os atributos não chave dependem da chave primária.

3. **Terceira Forma Normal (3FN):** Não existem atributos não chave que dependam de outros atributos não chave.
